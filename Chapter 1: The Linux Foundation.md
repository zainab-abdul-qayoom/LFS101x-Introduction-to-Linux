# Chapter 1: The Linux Foundation

## Easy Notes

* Linux is an open-source operating system kernel created by Linus Torvalds.
* The Linux Foundation is a non-profit organization that supports Linux and many other open-source projects.
* It provides training courses, certifications, and organizes events for developers worldwide.
* Linux is widely used in software development, cloud computing, DevOps, cybersecurity, and servers.
* This course focuses on three major Linux distribution families:

  * Red Hat Family
  * SUSE Family
  * Debian Family
* Different Linux distributions mainly differ in their package managers, software versions, and some system configurations.
* Ubuntu is widely used in cloud computing and is beginner-friendly.
* GNOME is the desktop environment used in this course.
* Linux skills are valuable for internships, technical interviews, and software engineering careers.

## Beginner-Friendly Terms

### Linux

Linux is an operating system kernel that helps software communicate with computer hardware.

> Think of Linux as the brain that manages the computer's resources.

### Linux Foundation

A non-profit organization that supports open-source projects like Linux, Kubernetes, PyTorch, and Node.js.

### Open Source

Open source means that anyone can view, study, and contribute to the source code of a software project.

### Linux Distribution (Distro)

A Linux distribution is a complete operating system built using the Linux kernel.

Examples:

* Ubuntu
* Debian
* Fedora
* openSUSE
* Linux Mint

> Think of Linux as flour and Linux distributions as different kinds of cakes made using that flour.

### Kernel

The kernel is the core part of an operating system. It manages:

* CPU
* Memory
* Hardware devices
* Running programs

The kernel acts as a bridge between software and hardware.

### Package Manager

A package manager is a tool used to:

* Install software
* Update software
* Remove software

Examples:

* apt
* dnf
* zypper

> Think of it as the Play Store for Linux.

### Repository

A repository is an online storage location that contains software packages which can be downloaded and installed safely.

### Red Hat Family

Includes:

* RHEL
* CentOS Stream
* Fedora
* Oracle Linux

Uses:

* dnf package manager

### SUSE Family

Includes:

* openSUSE
* SLES

Uses:

* zypper package manager

### Debian Family

Includes:

* Debian
* Ubuntu
* Linux Mint

Uses:

* apt package manager

### Ubuntu

Ubuntu is one of the most popular Linux distributions and is widely used in:

* Cloud Computing
* Servers
* Software Development

### Fedora

Fedora is often used to test new technologies before they are introduced into Red Hat Enterprise Linux.

### RHEL

RHEL stands for Red Hat Enterprise Linux.

It is commonly used by enterprises and organizations.

### CentOS Stream

CentOS Stream receives updates before they are included in RHEL.

### openSUSE

A free Linux distribution belonging to the SUSE family.

### SLES

SUSE Linux Enterprise Server is the enterprise version of SUSE Linux.

### Linux Mint

A beginner-friendly Linux distribution built on Ubuntu.

### Upstream

Upstream means the original source from which another project receives changes.

Example:

```text
Debian
   ↓
Ubuntu
   ↓
Linux Mint
```

Here:

* Debian is upstream for Ubuntu.
* Ubuntu is upstream for Linux Mint.

### RPM

RPM is a package format used by Red Hat-based Linux distributions.

### DNF

DNF is the package manager used by Red Hat-based distributions.

Examples:

* install software
* update software
* remove software

### APT

APT stands for Advanced Package Tool.

It is used in Debian-based distributions such as Ubuntu.

### Zypper

Zypper is the package manager used by SUSE-based distributions.

### GNOME

GNOME is a desktop environment that provides:

* Windows
* Icons
* Menus
* Settings

It gives Linux a graphical user interface.

### Cloud Computing

Cloud computing means using computing resources such as servers and storage over the internet.

Many cloud platforms use Linux servers.

### Server

A server is a computer that provides services to other computers over a network.

Examples:

* Web servers
* Database servers
* Cloud servers
