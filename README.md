# Introduction to Linux (LFS101x)

This repository contains my notes, command-line practice, Bash scripting exercises, and revision material from the Linux Foundation's **LFS101x: Introduction to Linux** course on edX.

Linux is a fundamental skill for software development, Cloud Computing, DevOps, cybersecurity, and system administration. I created this repository to document my learning journey and build a strong foundation for my future career in technology.

## Objectives

* Learn Linux fundamentals and system concepts.
* Practice Linux commands and shell operations.
* Understand the Linux boot process, filesystems, processes, and security principles.
* Develop basic Bash scripting skills.
* Build notes for revision before internships, technical interviews, and future projects.

## Topics Covered

* Linux Philosophy and Concepts
* Linux Basics and System Startup
* Graphical Interface
* System Configuration
* Command-Line Operations
* Linux Documentation
* Processes
* File Operations
* Text Editors
* User Environment
* Text Manipulation Utilities
* Network Operations
* Bash Shell Scripting
* Printing
* Local Security Principles
