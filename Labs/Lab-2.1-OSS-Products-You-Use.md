# Lab 2.1: What OSS Products Do You Use?

## Question
List some open source products you probably use day to day.

## My Answer (before checking solution)
- Android apps
- Microwave, car dashboard
- Headless devices — switches, automated systems, automobiles (no GUI needed)

## Official Course Solution
1. Android — Linux kernel powers most smartphones
2. Apache Web Server (httpd) — ~50% of web servers
3. Social media platforms — built on OSS components
4. Search engines — Google's data farms run Linux
5. Weather forecasting — supercomputers run Linux
6. Personal fitness devices (e.g. FitBit)
7. DVRs / set-top boxes
8. Medical devices — often embedded Linux

## What I Learned
Discovered the concept of **headless Linux** — systems running without 
a GUI, common in embedded devices and (later) cloud servers/containers.
